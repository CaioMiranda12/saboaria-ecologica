# Sprint 10.5 — Verificação por e-mail

Métodos exclusivos: desativado, e-mail ou TOTP. Para trocar, desative o método atual confirmando senha e código e entre novamente. E-mail usa Resend, remetente PASSWORD_RESET_FROM_EMAIL e JWT_SECRET para HMAC. Código de seis dígitos, cinco minutos, cinco tentativas por código e intervalo de 60 segundos por conta. Sem configuração de envio, opção de ativação fica indisponível. Não há fallback automático. Preserve JWT_SECRET e TOTP_ENCRYPTION_KEY. QR Code e recuperação administrativa continuam pendentes.

Execute npm install, npx prisma migrate deploy --config prisma7.config.ts, npx prisma generate --config prisma7.config.ts, npm run build, npm run dev. Faça backup antes. Teste com conta secundária: ativação por e-mail, login, código errado, expirado, reutilizado, reenvio, desativação, TOTP e ausência de configuração. Verifique também falhas de entrega e concorrência. Não homologado: build, testes de integração e envio real não executados. A confirmação de ativação exige entrega real; não habilite em conta principal antes de validar.
